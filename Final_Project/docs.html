📄 Розбір файлу: main.cpp

Головний файл програми. Відповідає за зв'язок між процесором, оперативною пам'яттю та відеокартою.

Глобальні змінні та константи

Символ / Змінна Тип даних Детальне пояснення
SCR_WIDTH / SCR_HEIGHT unsigned int Константи (800 і 600), що жорстко задають початковий розмір вікна програми у пікселях.
cameraPos glm::vec3 Вектор із 3 чисел (X,Y,Z). Задає фізичну точку у 3D-просторі, де знаходяться "очі" глядача.
deltaTime float Різниця в часі між поточним та попереднім кадром. Використовується як множник швидкості, щоб рух був плавним на будь-яких комп'ютерах.
VAO, VBO, EBO unsigned int Унікальні ідентифікатори (номери) буферів у пам'яті відеокарти. VBO зберігає координати, EBO — порядок їх з'єднання, VAO — запам'ятовує налаштування.

📐 Математика Fly-Камери

Функція mouse_callback розраховує напрямок погляду за допомогою сферичних координат (кутів Ейлера).

glm::vec3 front;
front.x = cos(glm::radians(yaw)) * cos(glm::radians(pitch));
front.y = sin(glm::radians(pitch));
front.z = sin(glm::radians(yaw)) * cos(glm::radians(pitch));
Символ / Змінна Детальне пояснення
yaw Кут нишпорення (рух голови вліво-вправо). Початкове значення -90.0f спрямовує камеру вздовж осі Z у глибину екрана.
pitch Кут тангажу (нахил голови вгору-вниз). Обмежений діапазоном [-89; 89], щоб уникнути математичної помилки Gimbal Lock.
glm::radians() Функція, що переводить градуси у радіани (оскільки тригонометричні функції C++ працюють виключно з радіанами).

💡 Шейдери: Модель Блінна-Фонга

Математична фізика світла розраховується для кожного пікселя екрана у файлі fragment.glsl.

Формула / Символ Значення у комп'ютерній графіці
dot(norm, lightDir) Скалярний добуток вектора нормалі та напрямку світла. Визначає розсіяне освітлення (Diffuse). Чим ближче кут до 0 (світло падає прямо), тим ближче результат до 1 (максимальна яскравість).
halfwayDir Половинний вектор (нормалізована сума вектора світла та вектора погляду камери). Це головна відмінність моделі Блінна-Фонга від звичайного Фонга.
pow(..., shininess) Піднесення до степеня. Візуально звужує та робить більш різким дзеркальний відблиск (Specular) на золотій поверхні.
attenuation Формула 1.0 / (K_c + K_l * d + K_q * d^2). Відповідає за фізично коректне затухання світла зі збільшенням відстані (d) до джерела.

⚙️ Збірка: CMakeLists.txt

Налаштування для компілятора MinGW.

Команда CMake Дія компілятора
add_subdirectory() Наказує компілятору зайти у вказану папку (наприклад, GLFW) і скомпілювати її вихідний код спеціально для нашого проєкту.
target_include_directories Вказує компілятору шляхи, де слід шукати заголовні файли (.h та .hpp) при зустрічі директиви #include.
target_link_libraries Фінальний етап (Лінкування). Зшиває наш скомпільований код (MyApp.exe) із бінарними файлами бібліотек OpenGL, GLFW та GLAD.
